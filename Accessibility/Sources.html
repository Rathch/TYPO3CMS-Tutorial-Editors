Sources and further reading 

The links below are the documents this chapter relies on. Read the primary document when a decision depends on the exact wording. A vendor article is labeled as one.

Guidelines and how to meet them 

  • Web Accessibility Initiative (WAI) — the W3C home for the standards, the teaching material, and the evaluation guidance.
  • Introduction to Web Accessibility — what web accessibility covers, and who benefits besides people with disabilities.
  • Web Content Accessibility Guidelines (WCAG) 2.1 — the W3C Recommendation. Content that meets WCAG 2.1 also meets WCAG 2.0.
  • Web Content Accessibility Guidelines (WCAG) 2.2 — the later Recommendation. The W3C encourages the current version when a policy is written or updated.
  • How to Meet WCAG 2.1 (Quick Reference) — filterable list of the requirements, with links to techniques.
  • Web accessibility laws and policies — the W3C list by country. The W3C states that the list is not complete and is not legal advice.

Writing and structure 

  • Writing for Web Accessibility — the W3C starting page for page titles, headings, link text, alternative text, captions, instructions, and plain language.
  • Headings — how heading levels form an outline.
  • Images — informative, decorative, and functional images.
  • An alt Decision Tree — a short sequence of questions for choosing the alternative text.
  • Tables — header cells.
  • Alt-texts: The Ultimate Guide — a practical guide from Axess Lab, with examples of weak and useful alternative text.

Checking a page 

  • Evaluating Web Accessibility: Overview — the W3C states that tools help and that a person still has to judge the page.
  • Easy Checks – A First Review of Web Accessibility — checks you can do in a browser.
  • Web Accessibility Evaluation Tools List — tools submitted by their providers. The W3C does not endorse them. Filters cover WCAG version, free and paid tools, and browser plugins.
  • Selecting Web Accessibility Evaluation Tools — how to decide what kind of tool you need.

European legislation 

  • Directive (EU) 2016/2102 — accessibility of the websites and mobile applications of public sector bodies.
  • Directive (EU) 2019/882 — the European Accessibility Act. National measures apply from 28 June 2025.
  • Accessibility of products and services — the EUR-Lex summary of what the Act covers and what it excludes.

Studies cited for the figures 

  • The WebAIM Million — the February 2026 evaluation of one million home pages. The figures in Accessibility for editors that name a percentage of home pages come from this report, unless another source is named.
  • Web Accessibility Statistics — AudioEye's article. The scan of about 400,000 pages, the image figures, and the link figures are theirs. AudioEye sells accessibility services. The article is included because it collects those content figures in one place, and it should be read as a vendor publication.
