# User settings {#user-settings}

The user settings module is where you can check your profile details, change
your password, and change how the backend looks and behaves.

First click your name in the top-right corner of the topbar, then select
**User Settings**.

![The avatar menu in the topbar with the User Settings entry](../Images/GeneratedScreenshots/UserSettings/UserSettingsModule.png)

You will see four tabs:

-   [Personal data](https://docs.typo3.org/permalink/t3editors:change-your-name-email-address-and-backend-language@main)
-   [Account security](https://docs.typo3.org/permalink/t3editors:change-your-password-and-set-up-multi-factor-authentication@main)
-   [Backend appearance](https://docs.typo3.org/permalink/t3editors:change-how-the-typo3-backend-looks-and-behaves@main)
-   [Personalization](https://docs.typo3.org/permalink/t3editors:fine-tune-editing-uploads-and-copying-in-the-backend@main)
