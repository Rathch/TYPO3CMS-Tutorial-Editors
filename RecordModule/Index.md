# Records {#the-list-module-and-clipboard}

**[Using the Records module](https://docs.typo3.org/permalink/t3editors:using-the-list-module-effectively@main)**

The list view displays a list of records stored on the current page, grouped by type.

**[Copy and paste](https://docs.typo3.org/permalink/t3editors:list-copy-paste@main)**

You can copy and paste records using the context menu and then choose
"copy" (or cut if you want to move the record instead).

**[Clipboard usage](https://docs.typo3.org/permalink/t3editors:advanced-clipboard-usage@main)**

Find out how to make get the most out of the clipboard with an overview of some
its extra features.

**[Mass Editing](https://docs.typo3.org/permalink/t3editors:mass-editing@main)**

The **Content > Records** module makes it possible to display the content of several
fields at once and gives you the ability edit several records with one action.
