# Next steps {#next-steps}

If your activities are not limited to editorial work, you may want to further
learn about TYPO3 CMS by following the [Sitepackage Tutorial](https://docs.typo3.org/m/typo3/tutorial-sitepackage/main/en-us/Index.html). This tutorial teaches you to create individual
templates using Fluid and some TypoScript. There are also some sitepackage
generators you can use.
